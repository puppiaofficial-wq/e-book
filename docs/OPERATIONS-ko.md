# 운영 가이드 (담당자용)

관리자 화면은 영어로 표기됩니다. 아래는 각 화면이 무엇을 하는지에 대한 설명입니다.

## 시작하기

1. 브라우저에서 `https://도메인/admin` 접속
2. 최초 1회: 이메일과 비밀번호(8자 이상)를 입력해 관리자 계정 생성
3. 이후에는 같은 주소에서 로그인

## Catalogs (카탈로그 목록)

* **Upload a PDF** 또는 점선 영역에 PDF를 끌어다 놓으면 변환이 시작됩니다.
  진행률이 실시간으로 표시되고, 끝나면 목록에 카드가 나타납니다.
* **New collection** — 시즌 등으로 묶는 그룹. 공개 라이브러리 페이지에서 제목으로 표시됩니다.
* 카드의 `LIVE` / `DRAFT` 배지로 게시 상태를 확인합니다.

> 원본이 양면(대지) PDF여도 그대로 올리면 됩니다. 자동으로 좌/우 페이지로 분할됩니다.

## 카탈로그 상세 화면

### Overview (기본 정보)
제목, 부제, 설명, 컬렉션, 주소(slug)를 설정합니다.
설명은 링크를 카톡·메일에 붙였을 때 나오는 미리보기 문구로도 쓰입니다.
주소는 한 번 공유한 뒤에는 바꾸지 마세요(기존 링크가 끊깁니다).

* **Replace source file** — 페이지만 교체. 목차·링크·공유 링크는 유지됩니다.
* **Duplicate catalog** — 설정을 그대로 복제(초안 상태로 생성).
* **Delete catalog** — 이미지·공유 링크·통계까지 영구 삭제.

### Publish & access (공개 설정)
* **Public** — 라이브러리 페이지에 노출, 누구나 열람
* **Unlisted** — 링크를 아는 사람만. 라이브러리에는 숨김
* **Password** — 공용 비밀번호 필요
* **Available from / until** — 시즌 카탈로그의 공개 기간
* **PDF download** — 원본 PDF 다운로드 허용 여부

### Contents (목차)
PDF 북마크에서 자동으로 들어옵니다. 페이지 번호·제목·단계(1~3)를 수정하고
**Save contents** 를 누르면 뷰어의 목차 버튼에 반영됩니다.

### Page links (페이지 링크)
페이지 이미지 위에서 **마우스를 드래그**하면 클릭 영역이 만들어집니다.
오른쪽에서 종류를 고르세요.

* Go to page — 페이지 번호 입력 (예: 12)
* Open a website — `https://...`
* Send an email — `mailto:` 없이 주소만 입력해도 됩니다
* Open a video — YouTube/Vimeo 주소

**Save links on this page** 로 해당 페이지만 저장합니다.
PDF에 이미 하이퍼링크가 있었다면 자동으로 들어와 있습니다.

### Design (디자인)
* **Page layout** — Automatic(권장) / 항상 양면 / 항상 단면
* **First image is printed page** — 표지가 인쇄물 1페이지가 아닐 때만 사용
* **Show the cover on its own** — 실제 책처럼 표지를 단독 표시 (기존 "시작페이지 0페이지"와 동일)
* **Right-to-left** — 오른쪽에서 왼쪽으로 넘기는 카탈로그
* 테마(Dark/Light), 강조색, 배경색, 로고 이미지 주소
* 뷰어 툴바에 표시할 버튼(공유·다운로드·인쇄)과 자동 숨김

### Share with buyers (바이어 공유) — 핵심 기능
바이어 한 명당 링크를 하나씩 만드세요.

| 항목 | 설명 |
| --- | --- |
| Label | 내부 관리용 이름 (예: 2026FW – 독일 A사) |
| Recipient | 받는 사람/회사 |
| Access code | 링크를 열 때 입력할 코드 (선택) |
| Expires after (days) | 며칠 뒤 자동 만료 (선택) |
| Maximum opens | 최대 열람 횟수 (선택) |
| Allow the PDF download | 이 링크로 PDF 다운로드 허용 여부 |

만들어진 링크는 **Copy** 로 복사하거나 **QR** 로 코드 이미지를 띄울 수 있습니다.
**Revoke** 하면 그 링크만 즉시 차단되고 다른 바이어의 링크는 그대로 살아 있습니다.

> 공유 링크는 카탈로그가 아직 게시(Publish) 전이어도 동작합니다.
> 출시 전 사전 공개용으로 사용하세요.

### Embed on your site (웹사이트 게시)
* **Direct link** — 뉴스레터·버튼·메신저에 넣을 주소
* **Embed in a web page** — `<iframe>` 코드. 그대로 복사해 붙여넣으면 됩니다.
  아래에 실제 동작 화면이 미리보기로 나옵니다.
* **QR code** — 전시회 배너·행택·라인시트 인쇄용 (SVG 다운로드 가능)

### Insights (통계)
최근 30일 기준 열람 수, 순 방문자, 읽은 페이지 수, 다운로드 수와
많이 본 페이지, 공유 링크별 성과, 유입 경로, 기기 비율을 보여줍니다.

## Settings (설정)

* 라이브러리 페이지 제목·문구·강조색·로고·연락처
* **Publish the library page** — 끄면 개별 카탈로그 링크로만 서비스합니다
* 컬렉션 이름 변경/삭제
* 관리자 이메일·비밀번호 변경

## 뷰어 단축키 (열람자용)

| 키 | 동작 |
| --- | --- |
| ← / → , Space | 이전 / 다음 페이지 |
| Home / End | 첫 / 마지막 페이지 |
| C | 목차 |
| S | 검색 |
| G | 전체 페이지 썸네일 |
| Z | 확대 보기 |
| H | 공유 |
| F | 전체화면 |
| Esc | 닫기 |

모바일에서는 좌우로 밀어서 넘기고, 화면 가운데를 한 번 누르면 툴바가 나타납니다.
두 손가락으로 벌리면 확대됩니다.

## 백업

`data/` 디렉토리 하나만 복사하면 전체 백업입니다.
카탈로그·이미지·공유 링크·통계가 모두 이 안에 있습니다.
