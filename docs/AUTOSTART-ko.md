# start.bat 없이 쓰기

> 컴퓨터를 켤 때마다 서버가 알아서 켜지게 해 둡니다.
> 그러면 검은 창을 열 일이 없고, 즐겨찾기만 누르면 바로 관리자 화면입니다.

## 등록

1. eBook Studio 폴더에서 **install-autostart.bat** 을 두 번 누릅니다
2. 잠깐 기다리면 관리자 화면이 저절로 열립니다
3. 그 주소를 **즐겨찾기에 추가**해 두세요

   ```
   http://localhost:8080/admin
   ```

이제 끝입니다. 다음부터는 컴퓨터를 켜면 서버가 조용히 켜져 있고,
즐겨찾기만 누르면 됩니다. 검은 창은 뜨지 않습니다.

## 끄고 켜기

| 하고 싶은 일 | 실행할 파일 |
| --- | --- |
| 서버 끄기 | `stop-server.bat` |
| 다시 켜기 | `run-hidden.vbs` (창 없이) 또는 `start.bat` (창 보면서) |
| 자동 시작 해제 | `remove-autostart.bat` |

## 새 버전으로 바꿀 때

1. `stop-server.bat` 으로 서버를 끕니다
2. 새 파일을 받아 폴더를 덮어씁니다
3. `install-autostart.bat` 을 한 번 더 실행합니다

버전이 맞는지는 관리자 화면 왼쪽 아래에서 확인할 수 있습니다.

## 자주 묻는 것

**다른 컴퓨터나 휴대폰에서도 이 주소로 들어갈 수 있나요?**
`localhost` 주소로는 안 됩니다. `localhost` 는 "이 컴퓨터"라는 뜻이라, 어느 컴퓨터에서
입력하든 그 컴퓨터 자신을 가리킵니다. 대신 **서버가 켜져 있는 컴퓨터의 IP 주소**를
쓰면 같은 사무실(같은 공유기) 안에서는 들어갈 수 있습니다. 아래 내용을 보세요.

**그럼 밖에서 카탈로그를 못 보나요?**
카탈로그는 볼 수 있습니다. 관리자 화면만 이 컴퓨터 전용입니다.
배포한 카탈로그는 `pages.dev` 주소로 전 세계 누구나 볼 수 있습니다.
바이어에게 보내는 것은 그 주소입니다.

**컴퓨터가 꺼져 있으면 바이어가 카탈로그를 못 보나요?**
볼 수 있습니다. 배포된 카탈로그는 클라우드플레어에 올라가 있어서
내 컴퓨터와 무관하게 항상 열립니다.

**백신이 막으면요?**
`run-hidden.vbs` 는 서버를 창 없이 켜는 세 줄짜리 스크립트입니다.
메모장으로 열어 내용을 확인할 수 있습니다. 백신이 계속 막으면
자동 시작을 쓰지 말고 `start.bat` 으로 켜시면 됩니다.

## 같은 사무실의 다른 PC에서 들어가기

서버는 이미 외부 접속을 받도록 켜져 있습니다. 주소와 방화벽 두 가지만 맞추면 됩니다.

### 1. 서버 컴퓨터의 IP 주소 확인

서버가 켜져 있는 컴퓨터에서 명령 프롬프트를 열고 (윈도우 키 + R → `cmd`)

```
ipconfig
```

`IPv4 주소` 줄을 찾습니다. 보통 `192.168.0.12` 같은 모양입니다.

### 2. 방화벽 열기

서버 컴퓨터에서 명령 프롬프트를 **관리자 권한으로** 열고 (시작 메뉴에서 `cmd` 를
찾아 오른쪽 클릭 → 관리자 권한으로 실행)

```
netsh advfirewall firewall add rule name="eBook Studio" dir=in action=allow protocol=TCP localport=8080
```

한 번만 하면 됩니다.

### 3. 다른 PC에서 접속

브라우저에 이렇게 입력합니다. `192.168.0.12` 자리에 1번에서 확인한 주소를 넣으세요.

```
http://192.168.0.12:8080/admin
```

`https` 가 아니라 `http` 입니다. 브라우저가 주소창에서 `https` 로 바꿔 버리면
접속되지 않습니다.

### 안 될 때

| 증상 | 원인 |
| --- | --- |
| 화면이 아예 안 뜸 | 방화벽이 막고 있습니다. 2번을 하세요 |
| *Failed to fetch* | 서버가 중간에 꺼졌거나, 주소를 `https` 로 열었습니다 |
| 주소를 모르겠음 | 공유기가 IP를 바꿀 수 있습니다. 접속이 끊기면 1번을 다시 확인하세요 |

### 주의

이 방법은 **같은 공유기에 연결된 기기**끼리만 됩니다. 집이나 외부에서는 열리지 않습니다.
그리고 사무실 안에서는 주소만 알면 누구나 관리자 화면을 열 수 있으니, 비밀번호를
쉬운 것으로 두지 마세요.

밖에서도 관리자 화면에 들어가야 한다면 Cloudflare Tunnel 로 고정 주소를 붙이는 방법이
있습니다. 무료이고, 서버 컴퓨터가 켜져 있어야 합니다. 필요하시면 만들어 드리겠습니다.

바이어가 보는 **카탈로그는 이 모든 것과 무관합니다.** 이미 클라우드플레어에 올라가 있어서
내 컴퓨터가 꺼져 있어도 전 세계 어디서나 열립니다.
