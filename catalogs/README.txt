이 폴더에 PDF 파일을 넣어 두세요.

start.bat (Windows) 또는 start.command (Mac) 를 실행하면
여기 있는 PDF가 자동으로 카탈로그로 변환되어 등록됩니다.

  - 파일 이름이 카탈로그 제목이 됩니다.
    예) PUPPIA 2026FW.pdf  ->  "PUPPIA 2026FW"
  - 양면(대지) PDF도 그대로 넣으시면 자동으로 좌/우 페이지로 나뉩니다.
  - 이미 등록한 파일은 다시 실행해도 중복 등록되지 않습니다.
  - 관리자 화면에서 직접 끌어다 놓는 방식도 그대로 사용할 수 있습니다.
