# 기존 e-Book 솔루션(aiiBook eCatalog Plus V2+) 과의 비교 및 이관 가이드

이 문서는 현재 운영 중인 솔루션을 분석한 결과와, 새 솔루션(eBook Studio)에서
각 기능이 어떻게 바뀌었는지를 정리한 것입니다.

## 1. 현재 사용 중인 방식 분석

업로드해 주신 매뉴얼과 관리자 화면을 기준으로 파악한 기존 운영 흐름입니다.

| 단계 | 기존 방식 |
| --- | --- |
| ① 원고 준비 | 반드시 **단면(1페이지 = 1장)** PDF 로 재구성. 양면(Spread) PDF는 사용 불가 |
| ② 변환 | Windows 전용 데스크톱 프로그램 **PitoMan** 실행 → 작은그림/큰그림 크기·품질·인코딩(utf-8 / euc-kr)을 수동 지정 → JPG + XML(coords.xml, search.xml) + TXT 생성 |
| ③ 업로드 | 관리자 모드(`/conf/`)에서 생성된 파일 전체를 수동 선택 후 업로드 |
| ④ 설정 | 카탈로그 설정(페이지 수, 작은그림/큰그림 픽셀값, 시작페이지 0/1, 배경), 스킨(PC용/모바일용 **각각 선택**), 효과, 전문가 설정(모바일 렌더링 방식), 목차, 페이지 링크 |
| ⑤ 서비스 | `common.js` 로드 후 `javascript:ecatalog('...','','폴더값','yes')` 팝업 호출, 또는 `ecatalog5.php?Dir=157` 직접 호출, 책장은 `include/catalist5.php` |
| 서버 | PHP / ASP / JSP 각각 별도 설치본, `catImage`·`flash`·`log`·`media` 디렉토리에 **chmod 777**, JSP는 WAS/WEB 분리 시 NFS·Samba 설정 필요 |
| 디렉토리 | `access`(모바일 전용), `flash`(.swf/.flv), `skin`(Flash 스킨), `skin5`(HTML5 스킨) 등 15개 |

### 구조적 한계

1. **Flash 잔재** — `flash/`, `skin/`(swf) 디렉토리와 동영상 .flv 처리. Flash는 2020년 12월 지원 종료.
2. **PC/모바일 이원화** — 스킨을 PC용·모바일용으로 따로 고르고, 모바일 전용 디렉토리(`access`)와 전용 렌더링 옵션(image 렌더링, 브라우저 핀치줌)을 따로 설정.
3. **Windows 종속** — 변환기가 Windows 전용 설치 프로그램. macOS·서버 자동화 불가.
4. **수작업 파라미터** — 이미지 픽셀값, 인코딩(euc-kr/utf-8), 페이지 수를 사람이 입력. 값이 틀리면 화면이 깨짐.
5. **양면 PDF 불가** — 룩북/카탈로그 원고는 대부분 양면 대지로 작업하므로 매번 단면 재구성 작업 발생.
6. **숫자 폴더값 식별자** — `Dir=157` 같은 값으로 링크를 만들어야 해서 주소가 의미를 갖지 못함.
7. **팝업 기반 배포** — `javascript:ecatalog(...)` 팝업은 팝업 차단·모바일·SNS 공유·메신저 미리보기에 모두 불리.
8. **바이어별 공유 개념 없음** — 비밀번호는 카탈로그 단위 하나뿐. 누가 열었는지 구분 불가, 개별 회수 불가.
9. **777 권한 / FTP 운영** — 보안·백업·이관 모두 수작업.

## 2. 기능 대응표

| 기존 기능 | 새 솔루션 |
| --- | --- |
| PitoMan 변환 (Windows) | 서버에서 자동 변환. PDF 업로드 → 렌더링·목차·링크·검색 텍스트 자동 추출 |
| 작은그림 / 큰그림 크기 수동 입력 | 자동. 뷰(1400px) / 확대(2400px) / 썸네일(280px) WebP 3종 자동 생성 |
| JPG 출력 | WebP 출력. 동일 화질 기준 **용량 약 1/3** |
| 인코딩(utf-8 / euc-kr) 선택 | 불필요. 전 구간 UTF-8 |
| 단면 PDF 필수 | 양면(대지) PDF 자동 감지·분할. `--split never` 로 끌 수 있음 |
| coords.xml / search.xml | `text.json` 한 파일. 검색 시 줄 단위 좌표로 본문 하이라이트 |
| 목차 수동 입력 | PDF 북마크에서 자동 생성 + 관리자에서 수정 |
| 페이지 링크 수동 좌표 지정 | PDF 내부 하이퍼링크 자동 추출 + 화면에서 드래그로 영역 지정 |
| PC 스킨 / 모바일 스킨 별도 선택 | 단일 반응형 뷰어. 화면 비율에 따라 양면·단면 자동 전환 |
| 효과 설정(넘김 방식·속도·여백 동기화) | 기본값으로 내장. 3D 페이지 넘김 + 드래그 넘김, 모바일은 슬라이드 |
| 전문가 설정(모바일 렌더링 방식) | 불필요 |
| 시작페이지 0/1 페이지 | *Design → Show the cover on its own* |
| 표시 시작페이지 | *Design → First image is printed page* |
| 서비스 시작/종료일 | *Publish & access → Available from / until* |
| 비밀번호 적용 | *Publish & access → Password*, 그리고 공유 링크별 접속 코드 |
| 책장 서비스 (`catalist5.php`) | `/library` 공개 라이브러리 페이지 + 컬렉션(시즌) 그룹 |
| 고정 링크값 (`Dir=157`) | 의미 있는 주소 `/b/2026fw`, 관리자에서 변경 가능 |
| `javascript:ecatalog(...)` 팝업 | 일반 URL + `<iframe>` 임베드 스니펫 + QR |
| 특정 페이지 호출 `&start=10` | `#p=10` |
| SNS 설정 | Open Graph 메타태그 자동 생성(표지 이미지 포함) + 뷰어 내 공유 시트 |
| 접속 통계 (log 디렉토리) | *Insights* 탭 — 열람 수, 순 방문자, 많이 본 페이지, 공유 링크별 성과, 유입 경로, 기기 |
| 아이디/비밀번호 분실 시 FTP로 PasSaD 삭제 | `npm run reset-admin -- 이메일 새비밀번호` |
| 유상 업그레이드 | 자체 소유 코드 |

## 3. 의도적으로 제외한 기능

가벼움과 관리 편의를 위해 아래는 이관하지 않았습니다. 필요하면 언제든 추가할 수 있습니다.

| 제외 항목 | 사유 |
| --- | --- |
| Flash 스킨(`skin/`, `.swf`), `.flv` 동영상 | Flash 지원 종료(2020-12). 동영상은 링크로 YouTube/Vimeo 열기로 대체 |
| 배경음악(`media/`) | 카탈로그 열람에 방해되고 모바일에서 자동재생 차단됨 |
| E-러닝 기능 | 강의형 기능으로 브랜드 카탈로그 용도와 무관 |
| CD 카탈로그(`cdinfo`) | 오프라인 CD 배포용 |
| 메일 발송 스크립트(`send/`) | 서버 메일 발송은 스팸 처리 위험. 공유 시트의 메일 앱 연동으로 대체 |
| 무료 스킨 다운로드 | 테마·강조색·로고 설정으로 대체 |
| 임시파일 암호화 | 공유 링크 토큰 + 접속 코드 + 만료·열람 제한으로 대체 |

## 4. 이관 절차

1. 새 서버(또는 동일 서버의 다른 디렉토리)에 설치하고 `PUBLIC_BASE_URL` 지정.
2. 원본 PDF를 카탈로그별로 준비. **단면 재구성 불필요** — 양면 대지 그대로 업로드.
   원본 PDF가 없고 기존 JPG만 있다면, 페이지 순서대로 정렬된 이미지 전체를
   한 번에 업로드하면 동일하게 동작합니다(단, 이 경우 본문 검색은 불가).
3. 컬렉션(예: 2026SS, 2026FW)을 만들고 카탈로그를 배치.
4. *Design* 에서 표지 단독 표시 여부, 강조색, 로고 지정.
5. *Publish & access* 에서 공개 범위 지정 후 게시.
6. 기존 사이트의 `javascript:ecatalog(...)` 링크를 `/b/<slug>` 주소로 교체.
7. 바이어에게는 *Share with buyers* 에서 만든 개별 링크를 발송.

### 기존 주소를 살려야 할 때

기존 `ecatalog5.php?Dir=157` 주소가 외부에 배포되어 있다면, 웹서버에서
리다이렉트를 걸어 두면 됩니다.

```
# nginx 예시
location = /e-book/ecatalog5.php {
  if ($arg_Dir = 157) { return 301 https://catalog.example.com/b/2026fw; }
  return 301 https://catalog.example.com/library;
}
```

| 항목 | 값 |
| --- | --- |
| 변환 시간 | 약 17초 (페이지당 0.55초) |

| 확대 이미지 합계 | 3.2 MB (2400px WebP) |
