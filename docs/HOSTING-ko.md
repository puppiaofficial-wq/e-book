# 어디에 올려서 운영할까 — 3가지 방법

질문 주신 세 가지에 대한 답입니다. 결론부터 말씀드리면 **웹호스팅 구독은 필수가 아니고,
지금 쓰시는 카페24 이미지호스팅만으로도 운영할 수 있습니다.**

## 한눈에 비교

| | A. 정적 배포 (카페24 쇼핑몰) | B. 정적 배포 (Cloudflare) | C. 서버 운영 |
| --- | --- | --- | --- |
| 추가 비용 | 0원 (이미 구독 중) | 0원 | 0원~월 1만원대 |
| PDF 변환 | 내 PC에서 자동 | 내 PC에서 자동 | 웹에서 업로드하면 자동 |
| 업로드 | FileZilla로 폴더 전송 | 폴더 끌어다 놓기 | 없음 |
| 뷰어·목차·검색·링크 | ○ | ○ | ○ |
| 홈페이지 임베드 | ○ | ○ | ○ |
| 바이어별 개별 링크 | △ (폴더 분리) | △ | ○ |
| 링크 회수·만료·열람 제한 | ✕ | ✕ | ○ |
| 열람 통계 | ✕ | ✕ | ○ |
| 비밀번호 | ✕ | ✕ | ○ |
| 확대 배율 | 내보낸 해상도까지 | 내보낸 해상도까지 | 제한 없음 |

**추천**: 지금은 A 또는 B로 시작하시고, 바이어가 언제 몇 페이지를 봤는지 추적이
필요해지는 시점에 C를 추가하시면 됩니다. 셋은 같은 프로그램이라 나중에 옮겨도
카탈로그를 다시 만들 필요가 없습니다.

---

## 1. "웹에서 PDF만 올리면 다 되는 방식"에 대해

**이미 그렇게 동작합니다.** 관리자 화면에 PDF를 끌어다 놓으면 페이지 이미지, 목차,
페이지 링크, 검색용 텍스트까지 서버가 알아서 만듭니다. PitoMan 같은 별도 설치
프로그램은 필요 없습니다.

다만 "서버가 알아서" 하려면 그 서버가 어딘가에서 돌고 있어야 합니다. 지금은 그 서버가
사장님 PC에서 돌고 있는 상태입니다(`start.bat`). 이걸 인터넷에 올릴지 말지가
아래 2·3번 질문의 핵심입니다.

### 용량 걱정에 대해

실측값입니다. 31페이지 PDF 기준입니다.

| 항목 | 용량 |
| --- | --- |
| 열람용 이미지 (1500px) | 2.4 MB |
| 확대용 이미지 (3000px) | 5.0 MB |
| 썸네일 | 0.3 MB |
| **카탈로그 1개 합계** | **약 7.7 MB** |

사진이 많은 68페이지 룩북이라면 **30~50 MB** 정도로 보시면 됩니다.
원본 PDF까지 보관해도 카탈로그 하나에 100 MB를 넘기기 어렵습니다.
1년에 시즌 4개씩 5년을 쌓아도 2 GB 수준이라, 요금제가 올라갈 만한 용량이 아닙니다.

> 참고: 기존 솔루션은 JPG로 저장했지만 이 프로그램은 WebP를 씁니다.
> 같은 화질에서 용량이 약 1/3입니다.

## 2. 카페24에 올리는 방식 (방법 A)

> **주의.** 카페24 **이미지 호스팅**에는 뷰어를 올릴 수 없습니다. 이미지 전용 상품이라
> HTML을 올려도 웹페이지로 열리지 않습니다. 카페24로 하시려면 **쇼핑몰 웹FTP**의
> `/web/upload/` 폴더를 쓰셔야 합니다. 단계별 안내는 [CAFE24-ko.md](CAFE24-ko.md) 에 있습니다.

### 어떻게 동작하나

1. 내 PC에서 `start.bat` 실행 → PDF를 넣고 카탈로그를 완성합니다
2. 검은 창에 아래 한 줄을 입력합니다

```
npm run export
```

3. 프로그램 폴더 안에 `export` 폴더가 생깁니다. 그 안에 카탈로그별 폴더가 들어 있고,
   **HTML·CSS·JS·이미지가 전부 들어 있는 완성된 웹사이트**입니다
4. FileZilla로 `export` 안의 폴더를 카페24 쇼핑몰의 `/web/upload/` 에 그대로 올립니다
5. 끝입니다. `https://내아이디.cafe24.com/web/upload/ebook/2026fw/index.html` 로 열립니다

서버가 필요 없습니다. 이미지만 올리는 게 아니라 뷰어까지 통째로 올라가기 때문에,
페이지 넘김·목차·검색·페이지 링크·썸네일이 전부 그대로 동작합니다.

### 확대 화질을 더 올리고 싶을 때

```
npm run export -- all --zoom 3600
```

확대용 이미지를 원본 PDF에서 3600px으로 다시 만들어 넣습니다.
PitoMan의 2000px 대비 1.8배입니다. 페이지당 약 3초 걸리므로 68페이지면 3~4분입니다.

### 바이어별 링크는 이렇게

정적 배포에는 링크 회수·만료 기능이 없습니다. 대신 폴더 이름을 남이 못 맞추게 만들면
같은 효과를 어느 정도 낼 수 있습니다.

```
npm run export -- 2026fw --out export/9f3a2c71
```

`https://이미지호스팅주소/9f3a2c71/2026fw/` 를 그 바이어에게만 보냅니다.
회수하려면 FTP에서 그 폴더를 지우면 됩니다.

### 비용

카페24 이미지 호스팅은 월 33,000원부터이고, 일 50GB 트래픽부터 시작합니다.
이미 구독 중이시라면 **추가 비용은 0원**입니다.

## 3. 완전 무료로 하고 싶을 때 (방법 B)

**Cloudflare Pages** 무료 요금제가 이 용도에 정확히 맞습니다.

* 정적 파일은 **대역폭 무제한**이고 요금이 붙지 않습니다
* 전 세계 CDN이라 해외 바이어에게도 빠릅니다
* 무료 SSL, 원하는 도메인 연결 가능
* 무료 한도는 월 500회 배포, 월 180분 빌드 시간입니다. 시즌마다 몇 번 올리는
  용도라면 걸릴 일이 없습니다

### 방법

1. `npm run export` 로 `export` 폴더를 만듭니다
2. Cloudflare 계정을 만들고 Pages → Upload assets 에서 폴더를 끌어다 놓습니다
3. 주소가 바로 나옵니다. 자체 도메인을 연결하셔도 됩니다

카페24와 Cloudflare 중 하나만 쓰셔도 되고, 둘 다 쓰셔도 됩니다.

## 4. 서버까지 올리고 싶을 때 (방법 C)

바이어별 링크 추적, 링크 회수, 열람 통계, 비밀번호, **무제한 확대**가 필요하면
프로그램 자체가 인터넷에서 돌아야 합니다. Node.js 20 이상이 돌아가는 곳이면 됩니다.

| 선택지 | 비용 | 메모 |
| --- | --- | --- |
| Oracle Cloud Always Free | 영구 무료 | ARM 2 OCPU / 12 GB, 스토리지 200 GB. 2026년 6월부터 4 OCPU에서 2 OCPU로 축소됐지만 이 용도에는 충분합니다. 가입 절차가 다소 번거롭습니다 |
| 소형 VPS (Vultr, Lightsail 등) | 월 1만원 내외 | 가장 단순하고 안정적입니다 |
| 카페24 웹호스팅 | 상품별 상이 | Node.js 지원 여부를 먼저 확인해야 합니다. 일반 웹호스팅은 PHP 전용인 경우가 많습니다 |

올리는 방법은 `README.md` 의 Deployment 항목과 `docker-compose.yml` 에 있습니다.

---

## 정리

* PDF만 올리면 되는 방식은 **이미 완성돼 있습니다**
* 용량은 카탈로그당 수십 MB라 요금제가 올라갈 걱정은 하지 않으셔도 됩니다
* 웹호스팅 구독은 **필수가 아닙니다**. `npm run export` 로 만든 폴더를
  카페24 이미지호스팅이나 Cloudflare Pages에 올리면 그걸로 끝입니다
* 바이어 추적과 링크 회수가 필요해지면 그때 서버를 얹으면 됩니다
