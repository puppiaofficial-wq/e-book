# 처음 실행하기 (Windows 기준)

컴퓨터 한 대에서 먼저 테스트해 보는 절차입니다. 전부 합쳐 10분 정도 걸립니다.

---

## 1단계. Node.js 설치 (최초 1회만)

1. https://nodejs.org/ko/download 접속
2. **LTS** 라고 표시된 버튼을 눌러 설치 파일을 내려받습니다
3. 내려받은 파일을 실행하고 **다음 → 다음 → 설치** 를 누릅니다
   (옵션은 아무것도 바꾸지 않아도 됩니다)
4. 설치가 끝나면 컴퓨터를 한 번 재시작합니다

> 이미 Node.js 가 깔려 있다면 이 단계는 건너뛰세요.

---

## 2단계. 프로그램 내려받기

1. GitHub 저장소 페이지에서 초록색 **Code** 버튼 → **Download ZIP**
2. 내려받은 ZIP 파일을 압축 해제
3. 압축을 푼 폴더를 원하는 위치로 옮깁니다 (예: `D:\ebook-studio`)

> 경로에 한글이나 공백이 있어도 동작하지만, 문제가 생기면 `D:\ebook` 처럼
> 짧은 영문 경로로 옮겨 보세요.

---

## 3단계. 카탈로그 PDF 넣기

압축을 푼 폴더 안에 **`catalogs`** 폴더가 있습니다.
여기에 카탈로그 PDF를 그대로 복사해 넣으세요.

```
ebook-studio\
 ├─ catalogs\
 │   └─ PUPPIA 2026FW.pdf      ← 여기에 넣습니다
 ├─ start.bat
 └─ ...
```

* **파일 이름이 그대로 카탈로그 제목이 됩니다.** `PUPPIA 2026FW.pdf` → "PUPPIA 2026FW"
* **양면(대지) PDF도 그대로 넣으시면 됩니다.** 자동으로 좌/우 페이지로 나뉩니다.
* PDF가 아직 없다면 이 단계를 건너뛰고, 나중에 관리자 화면에서 끌어다 놓아도 됩니다.

---

## 4단계. 실행

폴더 안의 **`start.bat`** 을 더블클릭합니다.

검은 창이 뜨면서 아래 순서로 진행됩니다.

1. `최초 실행 준비 중입니다...` — 처음 한 번만, 1~3분 소요
2. `변환 중: PUPPIA 2026FW.pdf` — 페이지 수만큼 진행 (60페이지 기준 약 35초)
3. 브라우저가 자동으로 열리면서 관리자 화면이 나타납니다

> **검은 창을 닫으면 서비스가 종료됩니다.** 테스트하는 동안은 켜 두세요.
> Mac 을 쓰신다면 `start.bat` 대신 `start.command` 를 더블클릭하세요.

---

## 5단계. 관리자 계정 만들기 (최초 1회만)

브라우저에 뜬 화면에서

1. **Email** — 사용하실 이메일 주소
2. **Password** — 8자 이상 비밀번호
3. **Create account** 클릭

이후에는 같은 주소에서 로그인만 하면 됩니다.
비밀번호를 잊으면 검은 창에서 `npm run reset-admin -- 이메일 새비밀번호` 로 재설정합니다.

---

## 6단계. 확인하기

관리자 화면(`http://localhost:8080/admin`)에 카탈로그 카드가 보입니다.

| 하고 싶은 것 | 위치 |
| --- | --- |
| 뷰어 화면 보기 | 카드 클릭 → 오른쪽 위 **Preview ↗** |
| 목차 확인/수정 | **Contents** 탭 |
| 표지 단독 표시, 색상, 로고 | **Design** 탭 |
| 바이어에게 보낼 링크 만들기 | **Share with buyers** 탭 |
| 홈페이지 삽입 코드 | **Embed on your site** 탭 |
| 열람 통계 | **Insights** 탭 |

뷰어에서 확인해 볼 것:

* 페이지 가장자리를 **마우스로 잡고 끌면** 실제 책처럼 넘어갑니다
* 오른쪽 위 돋보기 → 확대, 마우스 휠로 더 확대, 드래그로 이동
* 목차 버튼 → 항목 클릭 시 해당 페이지로 이동
* 검색 버튼 → 단어 입력 시 본문에서 찾아 노란색으로 표시

---

## 7단계. 바이어에게 보내보기

1. **Share with buyers** 탭
2. Label 에 관리용 이름 입력 (예: `2026FW - 독일 A사`)
3. 필요하면 Access code(접속 코드), Expires after(만료 일수) 입력
4. **Create share link** 클릭
5. 목록에 생긴 링크를 **Copy** 로 복사해 메일이나 메신저로 발송

> 지금은 `localhost` 주소라 **내 컴퓨터에서만** 열립니다.
> 바이어에게 실제로 보내려면 아래 "외부 공개" 단계가 필요합니다.

---

## 8단계. 외부에 공개하기 (실제 운영 시)

테스트가 끝나고 실제로 바이어와 홈페이지에 쓰려면 서버에 올려야 합니다.
방법은 두 가지입니다.

### 방법 A — 기존 웹 호스팅에 올리기
현재 e북 솔루션이 올라가 있는 서버에 Node.js 20 이상이 설치되어 있어야 합니다.
`README.md` 의 *Deployment* 항목에 nginx 설정 예시가 있습니다.

### 방법 B — 클라우드 서버 (권장)
월 1만원 내외의 소형 서버(AWS Lightsail, Vultr, 네이버 클라우드 등)면 충분합니다.
`docker-compose.yml` 의 도메인과 계정만 바꾸고 아래 한 줄이면 올라갑니다.

```bash
docker compose up -d
```

어느 쪽이든 `.env` 의 `PUBLIC_BASE_URL` 을 실제 도메인으로 지정해야
공유 링크와 QR 코드가 올바른 주소로 만들어집니다.

## 자주 막히는 곳

| 증상 | 해결 |
| --- | --- |
| 검은 창이 뜨긴 했는데 아무 글자도 안 나옴 | 예전 버전의 `start.bat` 입니다. ZIP을 다시 내려받거나 아래 "명령어로 직접 실행" 방법을 쓰세요 |
| `'npm' 은(는) 내부 또는 외부 명령...` | Node.js 설치 후 컴퓨터를 재시작하지 않은 경우입니다 |
| 검은 창이 켜졌다가 바로 꺼짐 | 폴더 경로에 특수문자가 있는지 확인, 짧은 영문 경로로 옮겨보세요 |
| 브라우저에 아무것도 안 나옴 | 주소창에 `http://localhost:8080/admin` 을 직접 입력해 보세요 |
| 8080 포트가 이미 사용 중 | `.env` 파일에서 `PORT=8090` 처럼 바꾼 뒤 다시 실행 |
| 변환이 너무 느림 | 페이지당 0.5초가 기준입니다. 100페이지면 1분 정도 걸립니다 |
| 검색이 안 됨 | 원본 PDF에 텍스트가 없는 경우(이미지로만 된 PDF)입니다 |

## 명령어로 직접 실행하기

`start.bat` 이 동작하지 않을 때 쓰는 방법입니다. 결과는 똑같습니다.

1. 프로그램 폴더를 탐색기에서 엽니다 (`package.json` 이 보이는 폴더)
2. 주소 표시줄을 클릭해 경로가 파란색으로 변하면, 그 자리에 `cmd` 를 입력하고 엔터
3. 검은 창이 뜨면 아래 세 줄을 한 줄씩 입력합니다

```
npm install
npm run autoimport
npm start
```

첫 줄은 1~3분, 둘째 줄은 PDF 변환 시간만큼 걸립니다.
셋째 줄 실행 후 브라우저에서 `http://localhost:8080/admin` 을 여세요.

## 백업

`data` 폴더 하나만 복사하면 전체 백업입니다.
카탈로그, 페이지 이미지, 공유 링크, 통계가 전부 이 안에 들어 있습니다.
